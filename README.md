Student Grade Tracker

## Project Description
The Student Grade Tracker is a Java-based application designed to manage student marks and calculate their grades. It helps users organize student performance information in a simple and efficient way.

## Features
- Manage student marks
- Calculate grades based on marks
- Display student performance
- Simple and easy-to-use Java program

## Technologies Used
- Java
- Object-Oriented Programming (if implemented in the code)

## How to Run the Program
1. Install the Java Development Kit (JDK) on your computer.
2. Download or clone this repository.
3. Open a terminal in the folder containing StudentGradeTracker.java.
4. Compile the program:
   bash
   javac StudentGradeTracker.java
   
5. Run the program:
   bash
   java StudentGradeTracker
   

## Requirements
- Java JDK installed
- A terminal or Java-supported IDE, such as VS Code
